# ricardas.io

Personal portfolio site built with Astro 6, React 19, and TypeScript.

## Stack

- **Framework**: Astro 6 (static output)
- **Interactive islands**: React 19 (contact form)
- **Styling**: Vanilla CSS with custom properties
- **Forms**: React Hook Form + Zod + Formspree
- **Fonts**: Inter via Astro Fonts API

## Development

```bash
npm install
npm run dev
```
